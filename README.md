# Student Registration Form — WS 301 Performance Task

A responsive, front-end Student Registration Form built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — form structure and required fields
- `style.css` — responsive layout, visual styles, and invalid-field styling
- `script.js` — validation, submit/reset handling, error messages, password visibility, and attribute manipulation
- `EXPLANATION.txt` — short explanation for the performance task

## Run the project
1. Extract the ZIP file.
2. Open the `StudentRegistration` folder.
3. Double-click `index.html` or open it in a browser.
4. Try submitting the empty form to see field-specific errors.
5. Enter valid details and submit to see the success message.
6. Use **Show/Hide** to toggle password visibility and **Reset Form** to restore the form.

No npm install, server, or database is required.

## Validation rules
- Required fields cannot be blank.
- Email must use a valid email format.
- Phone must be an 11-digit Philippine mobile number beginning with `09`.
- Date of birth cannot be in the future.
- A program, year level, and gender must be selected.
- Password must have at least 8 characters, a letter, and a number.
- Confirm password must match.
- Agreement checkbox must be checked.

This is a client-side class activity demo. It does not save registrations to a database or send information to a server.
